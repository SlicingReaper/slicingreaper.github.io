# slicingreaper.github.io

> ✍️ **Hand-coded.** Written by me, no AI.

My GitHub Pages site, live at **https://slicingreaper.github.io**.

It's my first web project from 2024: a single hand-written `index.html` with a heading, a welcome line and a GIF. I built it while learning how GitHub Pages works. It's kept as the starting point for a real portfolio.

## Files

| File | What |
|:--|:--|
| `index.html` | The whole site: plain HTML, no CSS framework, no JavaScript, no build step |

## Run it locally

Open `index.html` in a browser. Nothing to install.

## Deploy

GitHub Pages serves the `main` branch automatically. Push to `main` and the site updates within a minute or two.
